# Elevate Lite

Lightweight HTML component library using the G2 Elevate design system for rapid prototyping.

## Features

- 🎨 Complete Elevate design tokens (300+ CSS variables)
- 📦 Ready-to-use HTML component templates
- 🚀 No build tools required — just HTML + CSS
- ♿ WCAG 2.1 AA accessible
- 📱 Mobile responsive
- 🔗 1:1 fidelity with [UE Elevate](https://www.g2.test/elevate/lookbook)

## Quick Start

**Browse components:** [Live Demo](https://schildsg2.github.io/elevate-lite/)

**Use in your project:**

```html
<link rel="stylesheet" href="https://schildsg2.github.io/elevate-lite/tokens/elevate.css">
<link rel="stylesheet" href="https://schildsg2.github.io/elevate-lite/components/elevate.css">
```
